Add a wire

Add one line to net/wires.txt. The next round (within 5 minutes) probes it and it shows up here and on the badges.

id | group | kind | host:port | name | options
my-vps | vps | mp | 1.2.3.4:1922 | My VPS server | region=Asia
my-omp | custom | samp | play.example.com:7777 | My open.mp server

Kinds: mqtt (login + ping), mp (MP server list query), samp (open.mp / SA-MP query), tls, tcp, http, udp (mpnetd relay ping).
