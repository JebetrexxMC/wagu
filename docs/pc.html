How crossplay works

  1. The server is a real open.mp 1.6.7 server with the MP crossplay component. It runs 24/7 next to the other MP featured servers.
  2. PC players join on the open.mp/SA-MP side, and phones join on the MP side. PC players show up on phones as Name (PC), and phones show up on PC as M_Name.
  3. Chat crosses both ways. Damage between PC and phones is not shared yet.
  4. PC players reach the server through a playit.gg UDP tunnel. The playit agent runs on the 24/7 host, so nothing is installed on your computer. Watch it, or link the playit.gg account the first time, in the MP Tunnel console. Or use our own open-source tunnel: run curl -fsSL https://mpsamp-open.github.io/HiveMQ/frps-setup.sh | sudo bash on the HiveMQ VPS.
