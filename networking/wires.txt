# Add a line = a new wire: the 24/7 workflow (.github/workflows/netwire-247.yml) probes it on the next round
# (every 5 minutes), the status page (mpsamp-open.github.io/network.html) and the badges show it.
#
#   id | group | kind | host:port | name | options
#
# kind:  mqtt  MQTT 3.1.1 CONNECT/CONNACK + PINGREQ samples (options user= pass=)
#        mp    MP server, UDP PKT_QUERY -> PKT_INFO (same as the in-game server list)
#        samp  open.mp / SA-MP server, UDP SA-MP query 'p' + 'i'
#        tcp   TCP connect time (plain WebSocket, SSH, playit / frp tunnels)
#        tls   TLS ClientHello -> server hello / alert (MQTT 8883, WSS 8884, HTTPS 443; option sni=)
#        http  TCP + HEAD request (option path=/x)
#        udp   UDP echo: mpnetd relay ping, sockperf
#        lobby listed through the MQTT lobby only (no public address); filled in by tools/sources.py
# group: default featured crossplay region vps lobby emqx oracle xdp relay custom omp web
