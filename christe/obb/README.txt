Christe Multiplayer launcher OBB (main.<versionCode>.com.christe.mp.obb, a zip).
Put it in Android/obb/com.christe.mp/. The app unpacks it into Android/data/com.christe.mp/date2/resources
once (again when the file changes). Optional files: startup.mp4 (your own boot video), pictures, sounds.
The GTA SA OBB stays where it is (Android/obb/com.rockstargames.gtasa): Christe never copies it.
