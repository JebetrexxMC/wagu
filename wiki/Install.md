# Install

## GTA San Andreas

1. Install AML 1.4.0 on GTA SA 2.00. FLA 7.6 is supported but not needed.
2. Copy `libMP32.so` (32-bit game) or `libMP64.so` (64-bit game) to
   `/sdcard/Android/data/com.rockstargames.gtasa/mods/`.
3. Copy the `MP` folder from the download to
   `/sdcard/Android/data/com.rockstargames.gtasa/files/TYFMC/MP/`.
4. Start the game. Tap **[MultiPlayer]** on the main menu, or the **MP** bubble on the right edge of the screen.

Your settings are saved in `files/TYFMC/TYFMC.MP.ini`, section `[MP]`.

## MonetLoader mods (optional)

Copy `moonloader/` from `MP.zip` into the MonetLoader folder of the game. `mods_loader.lua` then starts everything in `moonloader/mods/`. See [MonetLoader mods](MonetLoader-Mods.md).

## Requirements

- Wi-Fi or mobile data. With no network at all you can't connect.
- The default and featured servers need the Discord login. A custom LAN server doesn't need it.
