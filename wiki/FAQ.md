# FAQ

**Where do I download MP?**
https://mpsamp-open.github.io

**I can't connect.**
Turn on Wi-Fi or mobile data. The default and featured servers need the Discord login. On LAN without internet, host your own custom server.

**Why doesn't HG / the cheat menu open?**
It only runs offline and on custom servers that allow MonetLoader cheats. It never runs on the default or featured servers. Server Management shows the reason.

**Others don't see my phone call animation.**
Both players need 4.13.58 or newer. The animation plays only on foot. It doesn't play in a car, while paused or when dead.

**Vice City: I don't see the [ MP ] button.**
Make sure you use the 4.13.56 or newer `.so` and the MP folder is in `files/TYFMC/MP` of Vice City. If it still does not show, send a screenshot of the game.

**Which game versions are supported?**
GTA SA 2.00 (32-bit and 64-bit) with AML 1.4.0, and GTA Vice City Mobile.
